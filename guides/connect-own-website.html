Setup walkthrough

1 / 5

1

Enable Your own website once

Sign in → open Connected booking → Booking providers → Your own website → Enable.

Copy the webhook URL we show you. It looks like:

https://www.thenetworkeruk.com/api/integrations/providers/own_site/webhook?token=…

One URL covers every event on your organiser account. Keep the token private — anyone with it can post bookings.

Open Connected booking
2

Publish the listing with your booking link

  1. Open the event → Set up tickets
  2. Choose Your own website → Continue to Connected setup
  3. Enter the price shown on The Networker UK
  4. Paste your checkout URL (the page where people pay on your site)
  5. Publish the listing

Copy the TNH event id shown on Connected setup — you will put it in every webhook message.

3

Send each booking to us

When a payment succeeds on your site (or in Zapier / Make), POST JSON to your webhook URL: 

{
  "eventId": "YOUR_TNH_EVENT_UUID",
  "orderId": "unique-booking-ref",
  "email": "buyer@example.com",
  "name": "Buyer Name",
  "company": "Acme Ltd",
  "jobTitle": "Founder",
  "quantity": 1,
  "amountPaid": 15,
  "status": "confirmed"
}

Required: eventId (TNH UUID), orderId (unique per booking), email.

Retries with the same orderId are treated as duplicates — safe to retry. Use status: "cancelled" if you refund.

4

Pick how you send it

  • Your developer — after successful checkout, your server POSTs the JSON (recommended).
  • Zapier / Make — trigger on a new paid order → Webhooks “POST” action → paste your TNH URL and map the fields.
  • Form plugins / CRM — any tool that can POST JSON to a URL after payment.

Example curl (replace the URL and values): curl -X POST 'YOUR_WEBHOOK_URL' -H 'Content-Type: application/json' -d '{"eventId":"…","orderId":"test-1","email":"you@example.com","name":"Test"}'

5

Check it worked

Easiest check: on Connected setup (or Booking providers), click Send test booking — no terminal needed. Or wait for a real sale, then:

  • Connected booking → Recent sync attempts should show own_site:accepted
  • Open the event’s Attendees list — the buyer should be there
  • After the event ends, they can leave a verified review on The Networker UK
Back to Connected booking
If something goes wrong
What you see What to try
invalid_webhook_token Re-enable Your own website on Connected booking and copy the new URL into your automation.
invalid_event_id / missing fields Send a real TNH event UUID in eventId, plus unique orderId and email.
Buyer missing on Attendees Check Recent sync attempts for own_site:accepted. Confirm the event is on Connected (not Link Out only).
No review invite Reviews go out after the event ends (~24h). The registration must exist on that TNH event first.

Stuck? Email hi@thenetworkeruk.com with your event name and a line from Recent sync attempts.

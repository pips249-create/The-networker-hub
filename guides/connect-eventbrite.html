Connect Eventbrite · full walkthrough

Prefer one step at a time? Part 1 · Part 2 · Part 3 · Part 4 · Part 5 · Part 6

1

Enable Eventbrite once

Sign in → open Booking system → choose Eventbrite. Press Enable Eventbrite if you do not yet see an account webhook URL.

The webhook URL appears on that same Eventbrite connection panel. It looks like:

https://www.thenetworkeruk.com/w/eb/…

Keep the www in the address. Without it, Eventbrite’s messages can fail.

Open Booking system
2

Paste that URL into Eventbrite

Saving your private token (step 3) usually registers this webhook for you. To check or paste by hand (once per Eventbrite account):

  1. Profile menu → Account settings → Webhooks
  2. Add a webhook (or edit an existing one)
  3. Paste the Networker UK URL from Booking system → Eventbrite as the Payload URL
  4. Tick order.placed, attendee.updated, and event.published
  5. “Events: All” is fine

You do not repeat this for every event.

3

Save your Eventbrite private token

Eventbrite’s ping is only a link to the order — not the buyer’s email. A private token from Eventbrite’s developer settings lets us load the buyer safely.

  1. Profile menu → Account Settings
  2. Left menu → Developer Links → API Keys
  3. If you already have an app: open it → Show API key, client secret and tokens. If not: click Create API Key and use the values below.
  4. Copy the Private token only (not the public key or client secret)
  5. On Connected setup / organiser connect, paste it and save
If you are creating a new API key — fill Eventbrite’s form like this:
  • Application URL — https://www.thenetworkeruk.com (homepage is correct here — do not paste your webhook URL)
  • OAuth Redirect URI — leave blank
  • Application Name — e.g. The Networker UK
  • Description — e.g. Sync Eventbrite ticket buyers to The Networker UK attendee list
Your personal webhook URL (https://www.thenetworkeruk.com/w/eb/…) belongs in Eventbrite Webhooks (step 2) — not on this form.

Without this token, sales may reach us but buyers will not appear on your attendee list.

4

Link each event

  1. Open the event → Set up tickets
  2. Choose Eventbrite → Continue to Connected setup
  3. Enter the price shown on The Networker UK
  4. Paste your Eventbrite event or checkout URL
  5. Confirm the numeric Eventbrite event id (use Use id from booking URL if offered)
  6. Save link, then Publish

Optional: tick copy title, date, and venue from Eventbrite onto your listing.

5

Check it worked

Place a small test order on Eventbrite (or wait for a real booking), then:

  • Connected booking → Recent sync attempts should show eventbrite:accepted
  • Open the event’s Attendees list — the buyer should be there

Only seeing eventbrite:webhook_ping? The message arrived but was not a full order — check the private token and event id link.

Back to Connected booking
If something goes wrong
What you see What to try
invalid_webhook_token Copy the webhook URL again from Connected booking and paste it into Eventbrite → Webhooks (include www).
event_not_linked On Connected setup, save the numeric Eventbrite event id for the event you sold.
Buyer missing on Attendees Confirm the private token is saved, the webhook includes order.placed, attendee.updated, and event.published, and Recent sync attempts shows accepted.
Worked once, then stopped Eventbrite keeps the URL you pasted. If we regenerated your token, paste the new URL into Eventbrite again.

Stuck? Email hi@thenetworkeruk.com with your event name and a line from Recent sync attempts.

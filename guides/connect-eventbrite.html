Connect Eventbrite

Keep selling tickets on Eventbrite. List the same event on The Networker UK — when someone buys, they appear on your attendee list here too.

← All guides

In plain English: Eventbrite still takes the payment. We need a short “ping” from Eventbrite after each sale so we can add the buyer to your Networker UK listing (attendees, reviews, round-ups).

You set that ping up once for your account. Then for each event you paste your Eventbrite link and save.

Open Connected booking →

What you need first

  • An organiser account on The Networker UK
  • A Connected booking plan (subscribe, or a complimentary pilot if we offered you one)
  • Your group’s organiser page assigned to Connected (under Organiser pages → Save assignment)
  • Access to your Eventbrite account settings (to paste a webhook URL)

Not on Connected yet? Open Connected booking in your dashboard and choose a plan. Link Out (£9.99 per event) only redirects buyers — it does not sync attendees.

How it fits together

  1. Someone finds you on The Networker UK They click Book and go to your Eventbrite checkout.
  2. They pay on Eventbrite Nothing changes for your buyers — same tickets, same Eventbrite fees.
  3. Eventbrite tells us about the order We add them to your attendee list on The Networker UK (when the link is set up correctly).

Step-by-step

  1. Enable Eventbrite on Connected booking (once)

    Sign in → open Connected booking → scroll to Booking providers → choose Eventbrite → Enable.

    Copy the webhook URL we show you. It looks like:

    https://www.thenetworkeruk.com/w/eb/…

    Important: keep the www in the address. Without it, Eventbrite’s messages can fail.

  2. Paste that URL into Eventbrite (once)

    In Eventbrite:

    1. Open your profile menu → Account settings → Webhooks
    2. Add a webhook (or edit an existing one)
    3. Paste the Networker UK URL as the Payload URL
    4. Set the action to order.placed
    5. “Events: All” is fine

    You only do this once per Eventbrite account — not for every event.

  3. Save your Eventbrite private token (once)

    Eventbrite’s ping only includes a link to the order — not the buyer’s email. We use a private token from Eventbrite’s developer settings to load the buyer (and other ticket holders) safely.

    On Connected setup or Booking providers, follow the Save API token / private token link (Eventbrite Developer links), paste the token, and save.

    Without this token, sales may reach us but buyers will not appear on your attendee list.

  4. Link each event (every listing)

    For each event you want synced:

    1. Open the event → Set up tickets
    2. Under Connected booking, choose Eventbrite → Continue to Connected setup
    3. Enter the price shown on The Networker UK (what visitors see before they leave)
    4. Paste your Eventbrite event or checkout URL
    5. Confirm the Eventbrite event id (the long number in the URL — use Use id from booking URL if we offer it)
    6. Optional: tick copy title, date, and venue from Eventbrite onto your Networker UK listing
    7. Save link for this event, then Publish

  5. Check it worked

    Place a small test order on Eventbrite (or wait for a real booking), then:

    • Connected booking → Recent sync attempts should show eventbrite:accepted
    • Open the event’s Attendees list — the buyer should be there

    If you only see eventbrite:webhook_ping, the message arrived but was not treated as a full order — check the private token and that the event id is linked.

If something goes wrong

What you see What to try
invalid_webhook_token Copy the webhook URL again from Connected booking and paste it into Eventbrite → Webhooks (include www). Use Fix webhook URL on our side if shown.
event_not_linked On Connected setup, save the numeric Eventbrite event id that matches the event you sold tickets for.
Buyer missing on Attendees Confirm the private token is saved, the webhook action is order.placed, and Recent sync attempts shows accepted.
Worked once, then stopped Eventbrite keeps the URL you pasted. If we regenerated your token, paste the new URL into Eventbrite again.

Using Ticket Tailor instead? Same idea, different buttons — see the short checklist in Connected booking under Booking providers, or ask Hubert.

Stuck? Email hi@thenetworkeruk.com with your event name and a line from Recent sync attempts.

Setup walkthrough

1 / 5

1

Open My events

Eventbrite connect lives on My events — not on Connected booking webhooks, and not on the organiser page Edit form.

  1. Sign in to The Networker UK
  2. Open your organiser dashboard
  3. In the sidebar, click My events
Open My events
2

Connect your Eventbrite account

On My events:

  1. Click the Connect Eventbrite row so it expands (this only opens the panel)
  2. Under Import onto, choose the organiser page that should receive events
  3. Click the primary Connect Eventbrite button inside the panel — that starts the connection (OAuth). Approve The Networker UK when Eventbrite asks.

If OAuth is unavailable, open Use a private API token instead in the same panel and follow the Eventbrite screenshots in step 3’s fallback.

3

Your Eventbrite list drops down

After a successful connect you return to My events. The panel status shows Connected and your Eventbrite events appear in the list underneath — ready to Import.

Fallback: connect with a private API token

Use this if the Connect Eventbrite button cannot open Eventbrite. Same result: Connected status + event list.

  1. On Eventbrite: Profile → Account Settings
  2. Left menu → Developer Links → API Keys
  3. Create API Key if needed, or open an app → Show API key, client secret and tokens
  4. Copy the Private token (not the public key / client secret)
  5. Back on My events → Connect Eventbrite → Use a private API token instead → paste → Save token & load events
4

Import each event onto your page

This is how events get onto The Networker UK:

  1. Confirm Import onto is the right organiser page
  2. On each Eventbrite row you want listed, click Import
  3. Complete listings (date + price + booking URL) publish; incomplete ones stay drafts until you finish them
  4. Rows already on the site show Already linked

You do not paste webhooks per event. Connecting the account once is enough for buyer sync after you Import (and publish) the listing.

5

Check a ticket sale synced

Place a small test order on Eventbrite (or wait for a real booking), then on our site:

  • Open the imported event → Attendees — the buyer should be there
  • Or check Booking system → Recent sync attempts for eventbrite:accepted
Back to My events
If something goes wrong
What you see What to try
Connect button fails / OAuth unavailable Use Use a private API token instead in the same My events panel (screenshots in step 3).
Connected but empty list Confirm events are live on Eventbrite. Click Refresh list. Draft Eventbrite events may not appear until they are live.
Import leaves a draft Add the missing price, booking URL, or date on the Networker UK listing, then publish.
Buyer missing on Attendees Confirm the event is Imported (not only Connected). Check Recent sync attempts for accepted. Reconnect if needed.
invalid_webhook_token Rare after connect. If shown, copy the webhook URL from Booking system / Connected booking and paste it into Eventbrite → Account settings → Webhooks (keep www; action order.placed).

Stuck? Email hi@thenetworkeruk.com with your organiser page name and a line from Recent sync attempts.

## Brand disambiguation

## Live data feeds (preferred for event recommendations)
- Events JSON: https://www.thenetworkeruk.com/api/public/events
  Filters: location, q, type, free=1, dateFrom, dateTo, page, limit (max 48), sort=date
  Example: /api/public/events?location=Manchester&limit=10
- Organisers JSON: https://www.thenetworkeruk.com/api/public/organisers
  Filters: location, q, guestVisits=1, page, limit
  Example: /api/public/organisers?location=Leeds&guestVisits=1
Use these feeds for “networking in [city] this week” style answers. Cite the event `url` or organiser `url`.
Public listing data is intended for discovery and recommendations with attribution links.

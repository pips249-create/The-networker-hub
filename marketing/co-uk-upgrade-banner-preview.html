How to put it on WordPress

  1. Keep current hosting. Take a full backup (DB + media) first.
  2. Install WPCode or Code Snippets (or edit the child theme header.php).
  3. Add a snippet that runs on the frontend header (or “Site Header”).
  4. Paste the HTML + CSS + small JS below.
  5. Publish, hard-refresh co.uk, click through to the hub.

Copy-paste: HTML (header)

<aside class="tnh-upgrade-banner" id="tnh-upgrade-banner" role="region" aria-label="Announcement">
  <div class="tnh-upgrade-banner__inner">
    <span class="tnh-upgrade-banner__eyebrow">Something new</span>
    <p class="tnh-upgrade-banner__copy">
      We’ve been working on <em>The Networker Hub</em> — same team, new platform.
    </p>
    <a class="tnh-upgrade-banner__cta" href="https://www.thenetworkerhub.com/for-organisers" target="_blank" rel="noopener">
      Check it out <span aria-hidden="true">→</span>
    </a>
  </div>
  <button type="button" class="tnh-upgrade-banner__close" id="tnh-upgrade-banner-close" aria-label="Dismiss announcement">&times;</button>
</aside>

Copy-paste: CSS

Copy the CSS block marked in this file’s <style> under “PASTE INTO WORDPRESS”, or use the compact version in marketing/co-uk-upgrade-banner-snippet.html.

Copy-paste: JS (dismiss for 14 days)

<script>
(function () {
  var KEY = "tnh_upgrade_banner_dismissed_v1";
  var el = document.getElementById("tnh-upgrade-banner");
  var btn = document.getElementById("tnh-upgrade-banner-close");
  if (!el) return;
  try {
    if (localStorage.getItem(KEY) === "1") { el.hidden = true; return; }
  } catch (e) {}
  if (btn) btn.addEventListener("click", function () {
    el.hidden = true;
    try { localStorage.setItem(KEY, "1"); } catch (e) {}
  });
})();
</script>

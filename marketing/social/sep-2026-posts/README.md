# Sep 2026 social assets

Ready-to-post images for the 3-week calendar (`../3-week-calendar-sep-2026.md`).

## What’s in here

1. **Event listing photos** — real organisers’ creatives (BITA, Get Connected, Belfast, etc.)
2. **UK pillar graphics** — regenerated Sep 2026 with **The Networker UK** logo, live CTAs, `thenetworkeruk.com` (no Hub / no “1st September”)
3. **Videos / PDFs / brand squares** — extras for LinkedIn document posts

Regenerate pillars any time:

```bash
node marketing/export-sep-2026-pillars.mjs
```

Source: `marketing/social/sep-2026-pillars.html`
